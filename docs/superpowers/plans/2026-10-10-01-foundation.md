# Plan 1 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the blank Expo scaffold into a signed-in, themed, navigable shell of EGX Analytics that every later plan builds on.

**Architecture:** The web repo's `src/app/lib/` becomes the single source of shared, platform-neutral code (API client, types, constants, maths, colour tokens); this app copies it into `src/shared/` with a sync script and fails verification on drift. Expo Router (`src/app/`) provides a protected stack: a login screen when signed out, and four bottom tabs plus stack routes when signed in. Auth tokens live in `expo-secure-store`; the shared API client is told how to read the token and what to do on a 401 at startup.

**Tech Stack:** Expo SDK 57, React Native 0.86, React 19.2, TypeScript 6, Expo Router, NativeWind 4.2.7 + Tailwind CSS 3, `@expo-google-fonts/outfit` + `@expo-google-fonts/jetbrains-mono`, `expo-secure-store`, Jest (`jest-expo`) + `@testing-library/react-native` 14.

**Spec:** [`2026-10-10-00-roadmap.md`](2026-10-10-00-roadmap.md) (contracts this plan must deliver: Shared code, Route map, Styling, UI kit, Providers, Testing, Environment) and the web product guide `../egx-api-fe/CLAUDE.md`.

## Review Focus

1. **Backend unreachable at boot with a stored session** — a person opening the app on the metro with no signal must land in the app with their cached identity, not on the login form (web behaviour). Pinned by the "network error keeps the cached session" test in Task 5.
2. **Wrong password** — must show the backend's message on the form and must NOT run the global sign-out path (a 401 from `/auth/login` is not an expired session). Pinned by the `loginRequest` test in Task 4 and the login-error test in Task 5.
3. **Token rejected mid-session (secret rotated / user disabled)** — any API 401 must drop the person to the login screen and wipe the secure store. Pinned by the "any API 401 signs out" test in Task 5 and the guard test in Task 7.
4. **`.env` missing or URL with a trailing slash** — the app must fail with a message naming `EXPO_PUBLIC_API_BASE_URL`, and `https://x/api/` must not produce `//tickers`. Pinned by the env tests in Task 4.
5. **Web app regression from the shared-lib refactor** — the web must still attach the token and redirect on 401 after `api.ts` stops importing `AuthProvider`. Pinned by the build + manual checks in Task 1 (the web repo has no test runner).

- [ ] **Step 2: Create `src/app/lib/apiConfig.ts`**

```ts
/**
 * Where the API client gets its base URL and token, and what it does on a 401.
 *
 * Everything in lib/ is SHARED with the egx-api-mobile app, which copies these
 * files verbatim (its `npm run sync:shared`). So this folder must stay
 * platform-neutral: no window, document, localStorage, next/* or components.
 * Each app registers its own token source and 401 handler at startup — the web
 * from AuthProvider, the mobile app from its secure token store.
 */
export interface ApiConfig {
  baseUrl: string;
  getToken: () => string | null;
  onUnauthorized: () => void;
}

const config: ApiConfig = {
  baseUrl: process.env.NEXT_PUBLIC_API_BASE_URL ?? "/api",
  getToken: () => null,
  onUnauthorized: () => {},
};

export function configureApi(next: Partial<ApiConfig>): void {
  Object.assign(config, next);
}

export function getApiConfig(): Readonly<ApiConfig> {
  return config;
}
```

   ```ts
   // ---- Auth ----

   /** A rejected sign-in, carrying the message to show on the form. */
   export class LoginError extends Error {}

   /**
    * POST /auth/login. Deliberately NOT routed through fetchJSON: a wrong
    * password is a 401, and that must surface as a message on the form, not
    * trigger the "your session expired" sign-out path.
    */
   export async function loginRequest(
     username: string,
     password: string
   ): Promise<{ token: string; user: AuthUser }> {
     const res = await fetch(`${base()}/auth/login`, {
       method: "POST",
       headers: { "Content-Type": "application/json" },
       body: JSON.stringify({ username, password }),
     });
     const data = await res.json().catch(() => ({}));
     if (!res.ok) {
       const msg =
         (typeof data?.detail === "string" && data.detail) ||
         (typeof data?.error === "string" && data.error) ||
         "Invalid username or password";
       throw new LoginError(msg);
     }
     return {
       token: data.access_token,
       user: {
         id: data.user?.id,
         username: data.user?.username,
         role: asRole(data.user?.role),
       },
     };
   }

   /** GET /auth/me — re-reads the role from the DB. A 401 signs out like any call. */
   export async function fetchMe(): Promise<AuthUser> {
     const data = await fetchJSON<{ id?: unknown; username?: unknown; role?: unknown }>(
       `${base()}/auth/me`
     );
     if (typeof data.id !== "string" || typeof data.username !== "string") {
       throw new Error("Malformed /auth/me response");
     }
     return { id: data.id, username: data.username, role: asRole(data.role) };
   }
   ```

- [ ] **Step 3: Write the sync script**

Create `scripts/sync-shared.mjs`:

```js
#!/usr/bin/env node
// Copies the platform-neutral lib/ files from the web app into src/shared/.
//   npm run sync:shared   -> write the copies
//   npm run check:shared  -> exit 1 if any copy differs from its source
// The web repo is the single source of truth; src/shared/ is never edited here.
import { access, mkdir, readFile, readdir, writeFile } from "node:fs/promises";
import path from "node:path";
import { fileURLToPath } from "node:url";

const root = path.resolve(path.dirname(fileURLToPath(import.meta.url)), "..");
const SOURCE_DIR = path.resolve(root, "../egx-api-fe/src/app/lib");
const TARGET_DIR = path.join(root, "src/shared");

const SHARED_FILES = [
  "api.ts",
  "apiConfig.ts",
  "auth.ts",
  "constants.ts",
  "positions.ts",
  "riskBands.ts",
  "theme.ts",
  "types.ts",
];

const header = (file) =>
  `// GENERATED by scripts/sync-shared.mjs from egx-api-fe/src/app/lib/${file}.\n` +
  `// Do not edit here: change the web repo, then run \`npm run sync:shared\`.\n`;

const check = process.argv.includes("--check");

if (check && process.env.SKIP_SHARED_CHECK === "1") {
  console.log("check:shared skipped (SKIP_SHARED_CHECK=1)");
  process.exit(0);
}

try {
  await access(SOURCE_DIR);
} catch {
  console.error(
    `Web repo not found at ${SOURCE_DIR}.\n` +
      "Clone egx-api-fe beside this repo, or set SKIP_SHARED_CHECK=1 on a build machine."
  );
  process.exit(1);
}

await mkdir(TARGET_DIR, { recursive: true });
const problems = [];

for (const file of SHARED_FILES) {
  const expected = header(file) + (await readFile(path.join(SOURCE_DIR, file), "utf8"));
  const target = path.join(TARGET_DIR, file);
  const actual = await readFile(target, "utf8").catch(() => null);
  if (actual === expected) continue;
  if (check) problems.push(`${file} differs from egx-api-fe`);
  else {
    await writeFile(target, expected);
    console.log(`synced ${file}`);
  }
}

for (const file of await readdir(TARGET_DIR)) {
  if (!SHARED_FILES.includes(file)) problems.push(`${file} is in src/shared but not in SHARED_FILES`);
}

if (problems.length) {
  console.error(`src/shared is out of date:\n  ${problems.join("\n  ")}\nRun npm run sync:shared and commit.`);
  process.exit(1);
}
if (check) console.log(`check:shared OK (${SHARED_FILES.length} files)`);
```

```ts
// A fake backend for tests. Register responses by method + path (the part
// after the /api base, without the query string) or a RegExp over the full
// URL. The most recent matching registration wins. Any unregistered request
// fails the test loudly instead of silently hanging.
type Reply = { status: number; body: unknown };
type Handler = (url: string, init?: RequestInit) => Reply | Promise<Reply>;
type Route = { method: string; path: string | RegExp; status: number; body: unknown; networkError?: boolean; handler?: Handler };
type Call = { method: string; url: string; headers: Record<string, string>; body: unknown };

let routes: Route[] = [];
let calls: Call[] = [];

const BASE = "https://api.test/api";

function matches(route: Route, method: string, url: string): boolean {
  if (route.method !== method) return false;
  if (route.path instanceof RegExp) return route.path.test(url);
  const pathOnly = url.replace(BASE, "").split("?")[0];
  return pathOnly === route.path;
}

export function mockFetch(method: string, path: string | RegExp, body: unknown, status = 200): void {
  routes.push({ method: method.toUpperCase(), path, body, status });
}

/** Answer with a function of the request — for routes whose reply depends on the query or body. */
export function mockFetchHandler(method: string, path: string | RegExp, handler: Handler): void {
  routes.push({ method: method.toUpperCase(), path, body: null, status: 200, handler });
}

export function mockFetchNetworkError(method: string, path: string | RegExp): void {
  routes.push({ method: method.toUpperCase(), path, body: null, status: 0, networkError: true });
}

export function fetchCalls(): Call[] {
  return calls;
}

export function installFetchMock(): void {
  routes = [];
  calls = [];
  global.fetch = jest.fn(async (input: RequestInfo | URL, init?: RequestInit) => {
    const url = String(input);
    const method = (init?.method ?? "GET").toUpperCase();
    const headers: Record<string, string> = {};
    new Headers(init?.headers ?? {}).forEach((value, key) => {
      headers[key.toLowerCase()] = value;
    });
    const body = typeof init?.body === "string" ? JSON.parse(init.body) : init?.body ?? null;
    calls.push({ method, url, headers, body });

    const route = [...routes].reverse().find((r) => matches(r, method, url));
    if (!route) throw new Error(`Unmocked fetch: ${method} ${url}`);
    if (route.networkError) throw new TypeError("Network request failed");
    const { status, body: replyBody } = route.handler
      ? await route.handler(url, init)
      : { status: route.status, body: route.body };
    return {
      ok: status >= 200 && status < 300,
      status,
      json: async () => replyBody,
    } as Response;
  }) as typeof fetch;
}
```

`src/auth/tokenStore.ts`:

```ts
import * as SecureStore from "expo-secure-store";

import { asRole, type AuthUser } from "@/shared/auth";

// Same key names as the web's localStorage keys, for recognisability.
const TOKEN_KEY = "egx.auth.token";
const USER_KEY = "egx.auth.user";

// SecureStore is async, but the shared API client asks for the token
// synchronously on every request — so the token is mirrored in memory and
// SecureStore is only read once, at boot (loadSession).
let cachedToken: string | null = null;

export function currentToken(): string | null {
  return cachedToken;
}

export interface StoredSession {
  token: string | null;
  user: AuthUser | null;
}

function parseUser(raw: string | null): AuthUser | null {
  if (!raw) return null;
  try {
    const parsed = JSON.parse(raw);
    if (parsed && typeof parsed.id === "string" && typeof parsed.username === "string") {
      // Optimistic only — /auth/me re-reads the role on every boot and the
      // backend enforces it regardless.
      return { id: parsed.id, username: parsed.username, role: asRole(parsed.role) };
    }
  } catch {}
  return null;
}

export async function loadSession(): Promise<StoredSession> {
  try {
    const [token, rawUser] = await Promise.all([
      SecureStore.getItemAsync(TOKEN_KEY),
      SecureStore.getItemAsync(USER_KEY),
    ]);
    cachedToken = token;
    return { token, user: parseUser(rawUser) };
  } catch {
    cachedToken = null;
    return { token: null, user: null };
  }
}

export async function saveSession(token: string, user: AuthUser): Promise<void> {
  cachedToken = token;
  await SecureStore.setItemAsync(TOKEN_KEY, token);
  await SecureStore.setItemAsync(USER_KEY, JSON.stringify(user));
}

export async function clearSession(): Promise<void> {
  cachedToken = null;
  await Promise.allSettled([
    SecureStore.deleteItemAsync(TOKEN_KEY),
    SecureStore.deleteItemAsync(USER_KEY),
  ]);
}
```

```tsx
import React, { createContext, useCallback, useContext, useEffect, useMemo, useState } from "react";

import { setupApi } from "@/lib/apiSetup";
import { fetchMe, LoginError, loginRequest } from "@/shared/api";
import type { AuthUser } from "@/shared/auth";

import { clearSession, loadSession, saveSession } from "./tokenStore";

interface AuthCtx {
  user: AuthUser | null;
  isAuthenticated: boolean;
  isAdmin: boolean;
  isLoading: boolean;
  error: string | null;
  login: (username: string, password: string) => Promise<void>;
  logout: () => Promise<void>;
}

const Ctx = createContext<AuthCtx | null>(null);

const UNREACHABLE = "Could not reach the server. Check your connection and try again.";

export function AuthProvider({ children }: { children: React.ReactNode }) {
  const [user, setUser] = useState<AuthUser | null>(null);
  const [isLoading, setIsLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  // Any 401 from the API means the token is dead (secret rotated, user
  // disabled). Drop to the login screen — the router guard does the navigation.
  const signOutLocally = useCallback(() => {
    void clearSession();
    setUser(null);
  }, []);

  useEffect(() => {
    setupApi(signOutLocally);
    let cancelled = false;

    (async () => {
      const { token, user: cached } = await loadSession();
      if (!token) {
        if (!cancelled) setIsLoading(false);
        return;
      }
      if (cached && !cancelled) setUser(cached);
      try {
        // Re-read the role from the DB on every boot, like the web.
        const fresh = await fetchMe();
        if (cancelled) return;
        setUser(fresh);
        await saveSession(token, fresh);
      } catch {
        // A 401 already signed us out through signOutLocally. A network error
        // keeps the cached session so the app still opens offline.
      } finally {
        if (!cancelled) setIsLoading(false);
      }
    })();

    return () => {
      cancelled = true;
    };
  }, [signOutLocally]);

  const login = useCallback(async (username: string, password: string) => {
    setError(null);
    try {
      const session = await loginRequest(username, password);
      await saveSession(session.token, session.user);
      setUser(session.user);
    } catch (e) {
      setError(e instanceof LoginError ? e.message : UNREACHABLE);
      throw e;
    }
  }, []);

  const logout = useCallback(async () => {
    await clearSession();
    setUser(null);
    setError(null);
  }, []);

  const value = useMemo<AuthCtx>(
    () => ({
      user,
      isAuthenticated: !!user,
      isAdmin: user?.role === "admin",
      isLoading,
      error,
      login,
      logout,
    }),
    [user, isLoading, error, login, logout]
  );

  return <Ctx.Provider value={value}>{children}</Ctx.Provider>;
}

export function useAuth(): AuthCtx {
  const ctx = useContext(Ctx);
  if (!ctx) throw new Error("useAuth must be used inside <AuthProvider>");
  return ctx;
}
```

```tsx
import { useAuth } from "@/auth/AuthProvider";
```

```tsx
export function LoginForm() {
  const { login, error } = useAuth();
  const [username, setUsername] = useState("");
  const [password, setPassword] = useState("");
  const [submitting, setSubmitting] = useState(false);

  const canSubmit = username.trim().length > 0 && password.length > 0 && !submitting;

  const onSubmit = async () => {
    if (!canSubmit) return;
    setSubmitting(true);
    try {
      // Same normalisation as the web form: usernames are stored lower-case.
      await login(username.trim().toLowerCase(), password);
    } catch {
      // `error` from useAuth carries the message.
    } finally {
      setSubmitting(false);
    }
  };

  return (
    <View className="gap-4">
      <TextField
        label="Username"
        value={username}
        onChangeText={setUsername}
        autoCapitalize="none"
        autoCorrect={false}
        autoComplete="username"
        textContentType="username"
        returnKeyType="next"
      />
      <TextField
        label="Password"
        value={password}
        onChangeText={setPassword}
        secureTextEntry
        autoComplete="current-password"
        textContentType="password"
        returnKeyType="go"
        onSubmitEditing={onSubmit}
      />
      {error ? (
        <View className="rounded-lg border border-loss/30 bg-loss/10 px-3 py-2">
          <AppText className="text-xs text-loss">{error}</AppText>

      ) : null}
```

```tsx
/**
 * Nothing renders until fonts are loaded AND the stored session has been
 * restored or ruled out. Without this, a signed-in person sees the login
 * screen flash on every cold start (the guard can't tell "not checked yet"
 * from "checked, signed out").
 */
function BootGate() {
  const [fontsLoaded, fontError] = useFonts(APP_FONTS);
  const { isLoading } = useAuth();
  const ready = (fontsLoaded || !!fontError) && !isLoading;

  useEffect(() => {
    if (ready) SplashScreen.hideAsync();
  }, [ready]);

  if (!ready) return null;
  return <RootNavigator />;
}
```

```tsx
import React, { createContext, useCallback, useContext, useEffect, useMemo, useState } from "react";

import { useAuth } from "@/auth/AuthProvider";
import { addToWatchlist, fetchWatchlist, removeFromWatchlist } from "@/shared/api";

interface WatchlistCtx {
  symbols: string[];
  loading: boolean;
  add: (sym: string) => void;
  remove: (sym: string) => void;
  has: (sym: string) => boolean;
}

const Ctx = createContext<WatchlistCtx | null>(null);

export function WatchlistProvider({ children }: { children: React.ReactNode }) {
  const [symbols, setSymbols] = useState<string[]>([]);
  const [loading, setLoading] = useState(true);
  const { isAuthenticated, user } = useAuth();

  useEffect(() => {
    if (!isAuthenticated) {
      setSymbols([]);
      setLoading(false);
      return;
    }
    let cancelled = false;
    setLoading(true);
    fetchWatchlist()
      .then((resp) => {
        if (!cancelled) setSymbols(resp.symbols || []);
      })
      .catch(() => {})
      .finally(() => {
        if (!cancelled) setLoading(false);
      });
    return () => {
      cancelled = true;
    };
  }, [isAuthenticated, user?.id]);

  // Optimistic, and rolled back if the API refuses — same as the web.
  const add = useCallback((sym: string) => {
    const upper = sym.toUpperCase();
    setSymbols((prev) => (prev.includes(upper) ? prev : [...prev, upper]));
    addToWatchlist(upper).catch(() => {
      setSymbols((prev) => prev.filter((s) => s !== upper));
    });
  }, []);

  const remove = useCallback((sym: string) => {
    const upper = sym.toUpperCase();
    let prevList: string[] = [];
    setSymbols((prev) => {
      prevList = prev;
      return prev.filter((s) => s !== upper);
    });
    removeFromWatchlist(upper).catch(() => {
      setSymbols(prevList);
    });
  }, []);

  const has = useCallback((sym: string) => symbols.includes(sym.toUpperCase()), [symbols]);

  const value = useMemo<WatchlistCtx>(() => ({ symbols, loading, add, remove, has }), [symbols, loading, add, remove, has]);

  return <Ctx.Provider value={value}>{children}</Ctx.Provider>;
}

export function useWatchlist(): WatchlistCtx {
  const ctx = useContext(Ctx);
  if (!ctx) throw new Error("useWatchlist must be used inside <WatchlistProvider>");
  return ctx;
}
```

```tsx
/**

    await SecureStore.setItemAsync("egx.auth.token", "test-token");
    await SecureStore.setItemAsync("egx.auth.user", JSON.stringify(user));
  }

  // `wrapper` (not inline JSX) so `rerender(ui)` keeps the providers mounted.
  const result = render(ui, {
```
