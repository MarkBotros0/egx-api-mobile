# Plan 2 — Charts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the mobile app a small SVG chart kit and a mobile twin of every web chart (same names, same props), shown together on a `__DEV__`-only `/dev/charts` gallery screen driven by JSON fixtures.

**Architecture:** Pure geometry (`d3-scale` + `d3-shape`) lives in `src/charts/kit/` as plain functions, unit-tested without rendering. One generic renderer, `XYChart`, turns a list of line / bar / band series plus reference lines into `react-native-svg` elements at a width measured with `onLayout`, and owns the tap-and-drag crosshair (`react-native-gesture-handler`) and its value readout. Each web chart becomes a thin component that maps its unchanged web props onto `XYChart` (or, for the gauge, sparkline, allocation and heatmap, draws its own small SVG / View tree), keeping the web's colours, labels and edge-case rules.

**Tech Stack:** Expo SDK 57, React Native 0.86, React 19.2, TypeScript 6, `react-native-svg` 15.15, `react-native-gesture-handler` ~2.32, `react-native-reanimated` 4 (gauge pulse), `d3-scale` 4, `d3-shape` 3, NativeWind 4, Jest (`jest-expo`) + `@testing-library/react-native` v14.

**Spec:** `docs/superpowers/plans/2026-10-10-00-roadmap.md` (binding contract — section *Charts contract*), plus the web sources this plan ports: `../egx-api-fe/src/app/components/{PriceChart,VolumeChart,IndicatorPanel,CompareChart,MonteCarloChart,CorrelationHeatmap,CompositeGauge,PortfolioSummary,StockCard,Watchlist}.tsx`, `../egx-api-fe/src/app/stock/[symbol]/page.tsx` (row building), and `../egx-api-fe/CLAUDE.md` (*Trendlines*, *Frontend Components → Charts / Composite Score*).

## Review Focus

1. **A chart drawn before it has a width, or at a width narrower than its y-axis** (first render, split screen, a card squeezed by a long label) — must render nothing or a degenerate-but-valid picture, never a path containing `NaN`. Pinned by Task 3 (`never emits NaN at a width narrower than the axis`) and Task 4 (`draws nothing until the parent has measured a width`).
2. **Series holding `null`, `undefined`, `NaN` or `Infinity`, or shorter than the date axis** (SMA 200 is null for 199 bars; a Monte Carlo percentile array can come back short) — gaps or connected lines exactly as the web's `connectNulls` says, readout shows `--`, no crash. Pinned by Task 2 (`computeDomain ignores non-finite values`), Task 3 (`treats NaN and missing trailing values as gaps`) and Task 9 (`a non-finite multiplier becomes a gap, not NaN`).
3. **The bar-count selector shrinks the data while the crosshair is showing** (user scrubs to bar 480 of 500, then taps "60") — the readout must disappear, not index past the end. Pinned by Task 4 (`drops the readout when the data shrinks under it`).
4. **Composite-score boundaries** (exactly 20, 19.4, 0, 100, above 100, negative, `NaN`, `Infinity`, `null`) — colour band, pulse (strictly below 20, as the web's code and comment insist) and ring clamp must match the web's `scoreColor`/`scoreBand`. Pinned by Task 6.
5. **Support/resistance/Fibonacci levels far outside the visible bars** (levels come from the full 400-bar history; the chart may show 60) — they must stretch the y-domain (web `ifOverflow="extendDomain"`) rather than vanish, while plain reference lines such as RSI 70/30 outside a domain are dropped. Pinned by Task 3 (`extends the domain to a reference line that asks for it`) and Task 7 (`levels from outside the visible bars are kept on the chart`).

Decisions locked here:

- **One renderer, many charts.** Recharts gave the web one engine for lines, bars and areas; `XYChart` is that engine for mobile. A chart component is only a props-to-series mapping, so a fix to axis ticks or the crosshair lands everywhere at once.
- **Geometry is pure and tested without rendering.** `react-native-svg` converts colours and strips handlers on its host elements, so asserting on rendered SVG props is brittle. Tests assert on `buildXYModel` output and on the text a user reads (readout, captions, legends, empty states). SVG elements carry `testID`s only where a count matters (trendline anchor dots).
- **Bands are drawn between two series.** The web paints an area from the chart floor and then "erases" below the lower series with an opaque background fill (Bollinger, Monte Carlo). `react-native-svg` + `d3.area().y0().y1()` draws the band itself, so no erase layer exists here. For Bollinger the picture is identical. For Monte Carlo it is a deliberate correction: the web's second erase (under p25) also erases the outer band between p5 and p25, so the web shows the lower half of the 5–95 fan as blank. Mobile shows the whole fan.

```ts
import { scaleLinear, type ScaleLinear } from "d3-scale";

export type Num = number | null | undefined;

/** The one rule for "is this a plottable value": finite number, else null. */
export function finiteOrNull(v: unknown): number | null {
  return typeof v === "number" && Number.isFinite(v) ? v : null;
}

export interface DomainOptions {
  /** Extra values the domain must contain (0 for bars, extendDomain reference lines). */
  include?: readonly number[];
  /** Fixed lower end (e.g. 0 for RSI and volume). */
  min?: number;
  /** Fixed upper end (e.g. 100 for RSI). */
  max?: number;
}

export function computeDomain(sets: readonly (readonly Num[])[], opts: DomainOptions = {}): [number, number] {
  let lo = Infinity;
  let hi = -Infinity;
  for (const set of sets) {
    for (const raw of set) {
      const v = finiteOrNull(raw);
      if (v === null) continue;
      if (v < lo) lo = v;
      if (v > hi) hi = v;
    }
  }
  for (const v of opts.include ?? []) {
    if (!Number.isFinite(v)) continue;
    if (v < lo) lo = v;
    if (v > hi) hi = v;
  }
  if (opts.min !== undefined) lo = opts.min;
  if (opts.max !== undefined) hi = opts.max;
  if (!Number.isFinite(lo) || !Number.isFinite(hi)) {
    lo = opts.min ?? 0;
    hi = opts.max ?? lo + 1;
  }
  if (lo === hi) {
    const pad = Math.abs(lo) * 0.01 || 1;
    return [opts.min ?? lo - pad, opts.max ?? hi + pad];
  }
  if (lo > hi) return [lo, lo + 1];
  return [lo, hi];
}

/** Linear y scale, domain minimum at `bottom`, rounded out to nice ticks (Recharts "auto"). */
export function makeYScale(domain: [number, number], top: number, bottom: number): ScaleLinear<number, number> {
  return scaleLinear().domain(domain).range([bottom, top]).nice(5);
}

/**
 * "point": first and last bar on the plot edges (Recharts LineChart).
 * "band": each bar centred in an equal slot (Recharts BarChart / ComposedChart with bars).
 */
export function xPositions(
  n: number,
  left: number,
  right: number,
  layout: "point" | "band",
): { xs: number[]; step: number } {
  if (n <= 0) return { xs: [], step: 0 };
  const w = Math.max(0, right - left);
  if (layout === "band") {
    const step = w / n;
    return { xs: Array.from({ length: n }, (_, i) => left + step * (i + 0.5)), step };
  }
  if (n === 1) return { xs: [left + w / 2], step: w };
  const step = w / (n - 1);
  return { xs: Array.from({ length: n }, (_, i) => left + step * i), step };
}

/** Recharts `interval="preserveStartEnd"` + `minTickGap`: first and last always, middle ones ≥ minGap apart. */
export function xTickIndices(xs: readonly number[], minGap: number): number[] {
  const n = xs.length;
  if (n === 0) return [];
  if (n === 1) return [0];
  const last = n - 1;
  const out = [0];
  for (let i = 1; i < last; i++) {
    const prev = xs[out[out.length - 1]];
    if (xs[i] - prev >= minGap && xs[last] - xs[i] >= minGap) out.push(i);
  }
  out.push(last);
  return out;
}

/** Index of the x closest to `x` (xs ascending); clamps outside; -1 when empty. */
export function nearestIndex(xs: readonly number[], x: number): number {
  const n = xs.length;
  if (n === 0) return -1;
  if (x <= xs[0]) return 0;
  if (x >= xs[n - 1]) return n - 1;
  let lo = 0;
  let hi = n - 1;
  while (hi - lo > 1) {
    const mid = (lo + hi) >> 1;
    if (xs[mid] <= x) lo = mid;
    else hi = mid;
  }
  return x - xs[lo] <= xs[hi] - x ? lo : hi;
}
```

```ts
import { area, curveLinear, curveMonotoneX, line, type CurveFactory } from "d3-shape";

export type Curve = "monotone" | "linear";

export interface Pt {
  x: number;
  /** Pixel y, or null for "no value at this bar". */
  y: number | null;
}

const CURVES: Record<Curve, CurveFactory> = {
  monotone: curveMonotoneX, // Recharts type="monotone"
  linear: curveLinear, // Recharts type="linear" — trendlines must stay straight
};

/**
 * SVG path for a line. connectNulls=false leaves a gap at every null (Recharts
 * default); connectNulls=true draws straight through them. Null when there is
 * nothing to draw.
 */
export function linePath(
  points: readonly Pt[],
  opts: { curve?: Curve; connectNulls?: boolean } = {},
): string | null {
  const pts = opts.connectNulls ? points.filter((p) => p.y !== null) : points;
  const d = line<Pt>()
    .x((p) => p.x)
    .y((p) => p.y as number)
    .defined((p) => p.y !== null)
    .curve(CURVES[opts.curve ?? "monotone"])(pts);
  return d ? d : null;
}

interface BandPt {
  x: number;
  y0: number | null;
  y1: number | null;
}

/**
 * Filled region between two pixel series (Bollinger envelope, Monte Carlo
 * fan). Drawn directly between the series — the web's "paint from the floor,
 * then erase below the lower series" trick is not needed here.
 */
export function bandPath(
  xs: readonly number[],
  lower: readonly (number | null)[],
  upper: readonly (number | null)[],
  opts: { curve?: Curve; connectNulls?: boolean } = {},
): string | null {
  let pts: BandPt[] = xs.map((x, i) => ({ x, y0: lower[i] ?? null, y1: upper[i] ?? null }));
  if (opts.connectNulls) pts = pts.filter((p) => p.y0 !== null && p.y1 !== null);
  const d = area<BandPt>()
    .x((p) => p.x)
    .y0((p) => p.y0 as number)
    .y1((p) => p.y1 as number)
    .defined((p) => p.y0 !== null && p.y1 !== null)
    .curve(CURVES[opts.curve ?? "monotone"])(pts);
  return d ? d : null;
}
```

```ts
  xTicks: { index: number; x: number; label: string }[];
  marks: Mark[];
  refLines: (RefLine & { py: number })[];
}

const PAD_TOP = 8;
const PAD_RIGHT = 4;
const BAR_FILL = 0.8; // Recharts' default 10% category gap on each side

export function buildXYModel(input: XYModelInput): XYModel {
  const { labels, series, width, height, yAxisWidth, xAxisHeight, xMinTickGap } = input;
  const n = labels.length;
  const refLines = input.refLines ?? [];

  const plot: PlotBox = {
    left: yAxisWidth,
    right: Math.max(yAxisWidth, width - PAD_RIGHT),
    top: PAD_TOP,
    bottom: Math.max(PAD_TOP, height - xAxisHeight),
  };

  const hasBars = series.some((s) => s.kind === "bars");
  const { xs, step } = xPositions(n, plot.left, plot.right, hasBars ? "band" : "point");
  const clip = (vals: SeriesValues) => Array.from({ length: n }, (_, i) => finiteOrNull(vals[i]));

  const valueSets: (number | null)[][] = [];
  for (const s of series) {
    if (s.kind === "band") valueSets.push(clip(s.lower), clip(s.upper));
    else valueSets.push(clip(s.values));
  }
  const include = [
    ...(hasBars ? [0] : []),
    ...refLines.filter((r) => r.extendDomain).map((r) => r.y),
  ];
  const scale = makeYScale(
    computeDomain(valueSets, { include, min: input.yDomain?.min, max: input.yDomain?.max }),
    plot.top,
    plot.bottom,
  );
  const [d0, d1] = scale.domain();
  const domain: [number, number] = [Math.min(d0, d1), Math.max(d0, d1)];
  const toPx = (vals: SeriesValues) => clip(vals).map((v) => (v === null ? null : scale(v)));

  const marks: Mark[] = series.map((s): Mark => {
    if (s.kind === "band") {
      return {
        kind: "band",
        id: s.id,
        fill: s.fill,
        d: bandPath(xs, toPx(s.lower), toPx(s.upper), { curve: s.curve, connectNulls: s.connectNulls }),
      };
    }
    if (s.kind === "bars") {
      const zero = scale(0);
      const w = step * BAR_FILL;
      const rects: BarRect[] = [];
      clip(s.values).forEach((v, index) => {
        if (v === null) return;
        const y = scale(v);
        rects.push({ index, x: xs[index] - w / 2, y: Math.min(y, zero), w, h: Math.abs(zero - y), color: s.colorAt(v, index) });
      });
      return { kind: "bars", id: s.id, rects };
    }
    const points = toPx(s.values);
    const anchors = (s.anchorIndices ?? [])
      .filter((i) => i >= 0 && i < n && points[i] !== null)
      .map((i) => ({ x: xs[i], y: points[i] as number }));
    return {
      kind: "line",
      id: s.id,
      color: s.color,
      width: s.width ?? 1.5,
      dash: s.dash,
      hidden: s.hidden ?? false,
      activeDot: s.activeDot ?? true,
      points,
      anchors,
      d: linePath(
        xs.map((x, i) => ({ x, y: points[i] })),
        { curve: s.curve, connectNulls: s.connectNulls },
      ),
    };
  });

  return {
    plot,
    xs,
    domain,
    yTicks: (input.yTicks ?? scale.ticks(5)).map((value) => ({ value, y: scale(value) })),
    xTicks: xTickIndices(xs, xMinTickGap).map((index) => ({ index, x: xs[index], label: labels[index] })),
    marks,
    refLines: refLines
      .filter((r) => r.y >= domain[0] && r.y <= domain[1])
      .map((r) => ({ ...r, py: scale(r.y) })),
  };
}
```

```ts
import { useCallback, useState } from "react";
import type { LayoutChangeEvent } from "react-native";

/**
 * Width of the chart's own box, from onLayout. 0 until the first layout, so
 * callers draw nothing rather than drawing at a guessed width. Never read
 * Dimensions here: a chart inside a padded card is narrower than the screen.
 */
export function useChartWidth(): { width: number; onLayout: (e: LayoutChangeEvent) => void } {
  const [width, setWidth] = useState(0);
  const onLayout = useCallback((e: LayoutChangeEvent) => {
    const next = Math.round(e.nativeEvent.layout.width);
    setWidth((prev) => (prev === next ? prev : next));
  }, []);
  return { width, onLayout };
}
```

```ts
import { useMemo, useState } from "react";
import { Gesture } from "react-native-gesture-handler";

import { nearestIndex } from "./scales";

/**
 * Tap-and-drag crosshair, replacing Recharts' hover tooltip.
 *  - Drag horizontally: the crosshair follows the finger (snapped to a bar)
 *    and stays where it was lifted.
 *  - Tap: show at the tapped bar; tap again to hide.
 *  - A mostly-vertical swipe fails the pan, so the page still scrolls.
 * Callbacks run on the JS thread (runOnJS) — they only set React state.
 */
export function useCrosshair(xs: readonly number[], testID: string) {
  const [index, setIndex] = useState<number | null>(null);

  const gesture = useMemo(() => {
    const at = (x: number) => {
      const i = nearestIndex(xs, x);
      return i < 0 ? null : i;
    };
    const pan = Gesture.Pan()
      .runOnJS(true)
      .activeOffsetX([-8, 8])
      .failOffsetY([-12, 12])
      .onStart((e) => setIndex(at(e.x)))
      .onUpdate((e) => setIndex(at(e.x)))
      .withTestId(`${testID}-pan`);
    const tap = Gesture.Tap()
      .runOnJS(true)
      .onEnd((e, success) => {
        if (success) setIndex((prev) => (prev === null ? at(e.x) : null));
      })
      .withTestId(`${testID}-tap`);
    return Gesture.Race(pan, tap);
  }, [xs, testID]);

  // The data can shrink under a visible crosshair (500 → 60 bars). An index
  // past the end is treated as "no crosshair" rather than read out of range.
  const safeIndex = index !== null && index < xs.length ? index : null;
  return { index: safeIndex, gesture };
}
```

```tsx
import Svg, { Circle, G, Line, Path, Rect, Text as SvgText } from "react-native-svg";

import { formatTick } from "./format";
import { CHART, CHART_FONT } from "./palette";
import { Readout, type ReadoutRow } from "./Readout";
import { finiteOrNull } from "./scales";

import { buildXYModel, type Mark, type PlotBox, type RefLine, type XYModel, type XYSeries } from "./xyModel";

const X_AXIS_HEIGHT = 18;
const EMPTY_XS: readonly number[] = [];

export interface XYChartProps {
  labels: readonly string[];
  series: readonly XYSeries[];
  height: number;
  refLines?: readonly RefLine[];
  yDomain?: { min?: number; max?: number };
  yTicks?: readonly number[];
  yTickFormat?: (v: number) => string;
  yAxisWidth?: number;
  xMinTickGap?: number;
  verticalGrid?: boolean;
  axisLine?: boolean;
  tickColor?: string;
  tickSize?: number;
  readoutTitle?: (label: string, index: number) => string;
  readoutFormat?: (value: number, seriesId: string) => string;
  testID?: string;
}

function MarkView({ mark }: { mark: Mark }) {
  if (mark.kind === "band") {
    return mark.d ? <Path d={mark.d} fill={mark.fill} stroke="none" /> : null;
  }
  if (mark.kind === "bars") {
    return (
      <G>
        {mark.rects.map((r) => (
          <Rect key={r.index} x={r.x} y={r.y} width={r.w} height={r.h} fill={r.color} />
        ))}
      </G>
    );
  }
  if (mark.hidden) return null;
  return (
    <G>
      {mark.d ? (
        <Path
          testID={`line-${mark.id}`}
          d={mark.d}
          stroke={mark.color}
          strokeWidth={mark.width}
          strokeDasharray={mark.dash}
          fill="none"
        />
      ) : null}
      {mark.anchors.map((a, i) => (
        <Circle
          key={i}
          testID={`anchor-${mark.id}`}
          cx={a.x}
          cy={a.y}
          r={3.5}
          fill={CHART.bg}
          stroke={mark.color}
          strokeWidth={1.5}
        />
      ))}
    </G>
  );
}

function RefLineView({ line, plot }: { line: RefLine & { py: number }; plot: PlotBox }) {
  const left = line.labelSide !== "right";
  return (
    <G>
      <Line
        x1={plot.left}
        x2={plot.right}
        y1={line.py}
        y2={line.py}
        stroke={line.color}
        strokeWidth={line.width ?? 1}
        strokeDasharray={line.dash}
      />
      {line.label ? (
        <SvgText
          x={left ? plot.left + 2 : plot.right - 2}
          y={line.py - 2}
          fontSize={line.labelSize ?? 9}
          fill={line.labelColor ?? line.color}
          fontFamily={CHART_FONT.sans}
          textAnchor={left ? "start" : "end"}
        >
          {line.label}
        </SvgText>
      ) : null}
    </G>
  );
}

function CrosshairView({ model, index }: { model: XYModel; index: number }) {
  const x = model.xs[index];
  return (
    <G>
      <Line
        testID="crosshair"
        x1={x}
        x2={x}
        y1={model.plot.top}
        y2={model.plot.bottom}
        stroke={CHART.crosshair}
        strokeWidth={1}
      />
      {model.marks.map((m) => {
        if (m.kind !== "line" || m.hidden || !m.activeDot) return null;
        const y = m.points[index];
        return y === null ? null : <Circle key={m.id} cx={x} cy={y} r={3} fill={m.color} />;
      })}
    </G>
  );
}

function readoutRows(
  series: readonly XYSeries[],
  index: number,
  format: ((value: number, seriesId: string) => string) | undefined,
): ReadoutRow[] {
  const rows: ReadoutRow[] = [];
  for (const s of series) {
    if (s.kind === "band" || s.inReadout === false) continue;
    const v = finiteOrNull(s.values[index]);
    const color = s.kind === "line" ? s.color : v === null ? CHART.tick : s.colorAt(v, index);
    rows.push({
      key: s.id,
      name: s.name,
      color,
      value: v === null ? "--" : format ? format(v, s.id) : v.toFixed(2),
    });
  }
  return rows;
}

/**
 * Generic line / bar / band chart. Measures its own width, so give it a
 * parent with a definite width (any normal block layout does).
 */
export function XYChart({
  labels,
  series,
  height,
  refLines,
  yDomain,
  yTicks,
  yTickFormat = formatTick,
  yAxisWidth = 40,
  xMinTickGap = 60,
  verticalGrid = true,
  axisLine = false,
  tickColor = CHART.tickDim,
  tickSize = 9,
  readoutTitle,
  readoutFormat,
  testID = "xy-chart",
}: XYChartProps) {
  const { width, onLayout } = useChartWidth();
  const model = useMemo(
    () =>
      width > 0 && labels.length > 0
        ? buildXYModel({
            labels,
            series,
            refLines,
            yDomain,
            yTicks,
            width,
            height,
            yAxisWidth,
            xAxisHeight: X_AXIS_HEIGHT,
            xMinTickGap,
          })
        : null,
    [labels, series, refLines, yDomain, yTicks, width, height, yAxisWidth, xMinTickGap],
  );
  const { index, gesture } = useCrosshair(model?.xs ?? EMPTY_XS, testID);

  return (
    <View testID={testID} onLayout={onLayout} style={{ height }}>
      {model ? (
        <GestureDetector gesture={gesture}>
          <View collapsable={false} style={{ width, height }}>
            <Svg width={width} height={height} testID={`${testID}-svg`}>
              <G>
                {model.yTicks.map((t) => (
                  <Line
                    key={`gy-${t.value}`}
                    x1={model.plot.left}
                    x2={model.plot.right}
                    y1={t.y}
                    y2={t.y}
                    stroke={CHART.grid}
                    strokeDasharray="3 3"
                  />
                ))}
                {verticalGrid
```

```tsx
import { useMemo } from "react";
import { View } from "react-native";
import { scaleLinear } from "d3-scale";
import Svg, { Path } from "react-native-svg";

import { CHART } from "./kit/palette";
import { linePath } from "./kit/paths";
import { computeDomain, xPositions } from "./kit/scales";

export interface SparklineProps {
  values: readonly number[];
  width?: number;
  height?: number;
}

/**
 * Colour is the move across the window the line DRAWS (~30 sessions), not
 * today's single-bar change: a stock down 22% on the month that ticked up
 * today must not draw a falling line in gain-green (web StockCard/Watchlist).
 */
export function sparklineModel(
  values: readonly number[],
  width: number,
  height: number,
): { d: string; color: string; up: boolean } | null {
  const vals = values.filter((v) => Number.isFinite(v));
  if (vals.length < 2 || width <= 2 || height <= 2) return null;
  const up = vals[vals.length - 1] >= vals[0];
  const y = scaleLinear()
    .domain(computeDomain([vals]))
    .range([height - 1, 1]);
  const { xs } = xPositions(vals.length, 1, width - 1, "point");
  const d = linePath(
    vals.map((v, i) => ({ x: xs[i], y: y(v) })),
    { curve: "monotone" },
  );
  return d ? { d, color: up ? CHART.gain : CHART.loss, up } : null;
}

export function Sparkline({ values, width = 64, height = 32 }: SparklineProps) {
  const model = useMemo(() => sparklineModel(values, width, height), [values, width, height]);
  if (!model) return null;
  return (
    <View testID="sparkline" accessible accessibilityLabel={model.up ? "Trend up" : "Trend down"} style={{ width, height }}>
      <Svg width={width} height={height}>
        <Path d={model.d} stroke={model.color} strokeWidth={1.5} fill="none" />
      </Svg>
    </View>
  );
}
```

```tsx
import { useMemo, useState } from "react";

import { arc, pie, type PieArcDatum } from "d3-shape";
import Svg, { G, Path } from "react-native-svg";

import { AppText } from "@/ui";

/** The web PortfolioSummary's PIE_COLORS, in order. */
export const ALLOCATION_COLORS = [
  "#4488ff", "#00ff88", "#ff3355", "#ffaa00", "#cc00ff",
  "#00ccff", "#ff6600", "#88ff00", "#ff00aa", "#aabb00",
] as const;

export interface AllocationSlice {
  name: string;
  value: number;
  color: string;
}

export interface AllocationProps {
  /** Sector → percent of portfolio (PortfolioMetrics.sector_allocation). */
  allocation: Record<string, number>;
}

export function allocationSlices(allocation: Record<string, number>): AllocationSlice[] {
  return Object.entries(allocation).map(([name, value], i) => ({
    name,
    value: Number.isFinite(value) ? value : 0,
    color: ALLOCATION_COLORS[i % ALLOCATION_COLORS.length],
  }));
}

/** Web donut: innerRadius 30, outerRadius 60 in a 160 box — scaled to `size`. */
export function donutArcs(slices: readonly AllocationSlice[], size: number): { slice: AllocationSlice; d: string }[] {
  const gen = arc<PieArcDatum<AllocationSlice>>()
    .innerRadius((size * 30) / 160)
    .outerRadius((size * 60) / 160);
  return pie<AllocationSlice>()
    .sort(null)
    .value((s) => Math.max(0, s.value))([...slices])
    .filter((a) => a.endAngle > a.startAngle)
    .map((a) => ({ slice: a.data, d: gen(a) ?? "" }))
    .filter((a) => a.d !== "");
}

/** The web's MOBILE branch: a 16pt stacked bar and a wrapped legend. */
export function AllocationBar({ allocation }: AllocationProps) {

  if (!slices.length) return null;
  return (
    <View testID="allocation-bar">
      <View className="mb-3 h-4 flex-row overflow-hidden rounded-full">
        {slices.map((s) => (
          <View
            key={s.name}
            className="h-full"
            style={{
              width: `${s.value}%` as `${number}%`,
              backgroundColor: s.color,
              minWidth: s.value > 0 ? 4 : 0,
            }}
          />
        ))}
      </View>
      <View className="flex-row flex-wrap gap-x-4 gap-y-1.5">
        {slices.map((s) => (
          <View key={s.name} className="flex-row items-center gap-1.5">
            <View className="h-2.5 w-2.5 rounded-full" style={{ backgroundColor: s.color }} />
            <AppText className="text-xs text-white/50">
              {s.name} ({s.value.toFixed(0)}%)
            </AppText>
          </View>
        ))}
      </View>
    </View>
  );
}

/** The web's DESKTOP branch: a donut. Tap a slice or legend item to read its share. */
export function AllocationDonut({ allocation, size = 160 }: AllocationProps & { size?: number }) {
  const slices = useMemo(() => allocationSlices(allocation), [allocation]);
  const arcs = useMemo(() => donutArcs(slices, size), [slices, size]);
  const [selected, setSelected] = useState<string | null>(null);
  if (!slices.length) return null;

  const sel = slices.find((s) => s.name === selected) ?? null;
  const toggle = (name: string) => setSelected((prev) => (prev === name ? null : name));

  return (
    <View testID="allocation-donut" className="items-center gap-3">
      <Svg width={size} height={size}>
        <G transform={`translate(${size / 2} ${size / 2})`}>
          {arcs.map((a) => (
            <Path
              key={a.slice.name}
              d={a.d}
              fill={a.slice.color}
              opacity={sel && sel.name !== a.slice.name ? 0.35 : 1}
              onPress={() => toggle(a.slice.name)}
            />
          ))}
        </G>
      </Svg>
      {sel ? (
        <AppText testID="allocation-readout" className="font-mono text-xs text-white">
          {sel.name}: {sel.value.toFixed(1)}%
        </AppText>
      ) : null}
      <View className="flex-row flex-wrap justify-center gap-x-2">
        {slices.map((s) => (
          <Pressable
            key={s.name}
            accessibilityRole="button"
            accessibilityState={{ selected: s.name === selected }}
            onPress={() => toggle(s.name)}
            className="min-h-[44px] flex-row items-center gap-1.5 px-1"
          >
            <View className="h-2 w-2 rounded-full" style={{ backgroundColor: s.color }} />
            <AppText className="text-[10px] text-white/50">
              {s.name} ({s.value.toFixed(0)}%)
            </AppText>
          </Pressable>
        ))}
      </View>
    </View>
  );
}
```

```tsx
import type { CompositeSignal } from "@/shared/types";

import { CHART_FONT } from "./kit/palette";

export interface CompositeGaugeProps {
  score: number | null | undefined;
  signal?: CompositeSignal | null;
  size?: "sm" | "md" | "lg";
  showLabel?: boolean;
}

/** Linear interpolation between two hex colours. */
function lerpColor(a: string, b: string, t: number): string {
  const clamp = (v: number) => Math.max(0, Math.min(1, v));
  t = clamp(t);
  const pa = parseInt(a.slice(1), 16);
  const pb = parseInt(b.slice(1), 16);
  const ar = (pa >> 16) & 0xff;
  const ag = (pa >> 8) & 0xff;
  const ab = pa & 0xff;
  const br = (pb >> 16) & 0xff;
  const bg = (pb >> 8) & 0xff;
  const bb = pb & 0xff;
  const r = Math.round(ar + (br - ar) * t);
  const g = Math.round(ag + (bg - ag) * t);
  const bl = Math.round(ab + (bb - ab) * t);
  return `#${((r << 16) | (g << 8) | bl).toString(16).padStart(6, "0")}`;
}

/**
 * Colour for a composite score. Bands are lower-bound-inclusive, matching
 * `scoreBand` and the backend's `classify_signal` — a score of 60 is a green
 * BUY ring, a 20 is Sell (no Strong-Sell red, no pulse). Port of the web's
 * scoreColor; keep the two identical.
 */
export function scoreColor(score: number): string {
  switch (scoreBand(score)) {
    case "strong_sell":
      return lerpColor("#ff3355", "#ff6644", score / SCORE_STRONG_SELL_MAX);
    case "sell":
      return lerpColor("#ff6644", "#ffaa00", (score - SCORE_STRONG_SELL_MAX) / (SCORE_SELL_MAX - SCORE_STRONG_SELL_MAX));
    case "hold":
      return lerpColor("#ffaa00", "#c8b400", (score - SCORE_SELL_MAX) / (SCORE_HOLD_MAX - SCORE_SELL_MAX));
    case "buy":
      return lerpColor("#00cc66", "#00e07a", (score - SCORE_HOLD_MAX) / (SCORE_BUY_MAX - SCORE_HOLD_MAX));
    case "strong_buy":
      return lerpColor("#00e07a", "#00ff88", Math.min(1, (score - SCORE_BUY_MAX) / (100 - SCORE_BUY_MAX)));
  }
}

const SIZES = {
  sm: { box: 40, stroke: 4, font: 11, signalFont: 0 },
  md: { box: 96, stroke: 8, font: 22, signalFont: 10 },
  lg: { box: 160, stroke: 12, font: 40, signalFont: 13 },
} as const;

const TRACK = "rgba(255,255,255,0.07)";
const NO_SCORE_TEXT = "rgba(255,255,255,0.3)";
const SIGNAL_TEXT = "rgba(255,255,255,0.6)";

/** Tailwind animate-pulse: opacity 1 → 0.5 → 1, 2s, forever. */
function Pulse({ active, children }: { active: boolean; children: ReactNode }) {
  const opacity = useSharedValue(1);
  useEffect(() => {
    if (!active) {
      cancelAnimation(opacity);
      opacity.set(1);
      return;
    }
    opacity.set(
      withRepeat(withSequence(withTiming(0.5, { duration: 1000 }), withTiming(1, { duration: 1000 })), -1),
    );
    return () => cancelAnimation(opacity);
  }, [active, opacity]);
  const style = useAnimatedStyle(() => ({ opacity: opacity.get() }));
  return (
    <Animated.View testID={active ? "gauge-pulse" : undefined} style={style}>
      {children}
    </Animated.View>
  );
}

export function CompositeGauge({ score, signal, size = "md", showLabel }: CompositeGaugeProps) {
  const dims = SIZES[size];
  const cx = dims.box / 2;
  const cy = dims.box / 2;
  const r = (dims.box - dims.stroke) / 2;
  const circumference = 2 * Math.PI * r;

  const hasScore = typeof score === "number" && Number.isFinite(score);
  const value = hasScore ? score : 0;
  const displayScore = hasScore ? Math.round(value) : null;
  const color = hasScore ? scoreColor(value) : NO_SCORE_TEXT;
  const pct = hasScore ? Math.max(0, Math.min(100, value)) / 100 : 0;
  const dashOffset = circumference * (1 - pct);

  // Only a genuine Strong Sell (below 20) gets the alarm animation.
  const pulsing = hasScore && scoreBand(value) === "strong_sell";
  const label = showLabel ?? size !== "sm";
  const a11y = hasScore
    ? `Composite score ${displayScore}${signal ? ` ${signal}` : ""}`
    : "Composite score unavailable";

  return (
    <View testID="composite-gauge" accessible accessibilityLabel={a11y} className="items-center">
      <Pulse active={pulsing}>
        <Svg width={dims.box} height={dims.box} viewBox={`0 0 ${dims.box} ${dims.box}`}>
          <Circle cx={cx} cy={cy} r={r} fill="none" stroke={TRACK} strokeWidth={dims.stroke} />
          {hasScore ? (
            <Circle
              cx={cx}
              cy={cy}
              r={r}
              fill="none"
              stroke={color}
              strokeWidth={dims.stroke}
              strokeDasharray={`${circumference} ${circumference}`}
              strokeDashoffset={dashOffset}
              strokeLinecap="round"
              transform={`rotate(-90 ${cx} ${cy})`}
            />
          ) : null}
          <SvgText
            x={cx}
            y={cy + dims.font * 0.35}
            textAnchor="middle"
            fontSize={dims.font}
            fontFamily={CHART_FONT.monoSemibold}
            fill={hasScore ? color : NO_SCORE_TEXT}
          >
            {displayScore === null ? "—" : String(displayScore)}
          </SvgText>
          {label && signal && size !== "sm" ? (
            <SvgText
              x={cx}
              y={cy + dims.font * 0.7 + 4 + dims.signalFont * 0.35}
              textAnchor="middle"
              fontSize={dims.signalFont}
              fontFamily={CHART_FONT.sansSemibold}
              fill={SIGNAL_TEXT}
            >
              {signal}
            </SvgText>
          ) : null}
        </Svg>
      </Pulse>
    </View>
  );
}
```

```tsx
export function buildPriceSeries(
  data: readonly PriceDataPoint[],

/**
 * Levels come from the full ~400-bar history while the chart may show 60
 * bars, so every one extends the domain — the web learned this when levels
 * named in the Key Levels card were missing from the chart below it.
 */
export function priceRefLines(
  supports?: readonly SupportLevel[],
  resistances?: readonly SupportLevel[],
  fibonacci?: FibonacciLevels | null,
): RefLine[] {
  const out: RefLine[] = [];
  supports?.forEach((s, i) =>
    out.push({
      id: `support-${i}`,
      y: s.price,
      color: withAlpha(CHART.gain, 0.4),
      dash: "4 4",
      label: `S ${s.price.toFixed(2)}`,
      labelSide: "left",
      labelSize: 9,
      labelColor: withAlpha(CHART.gain, 0.5),
      extendDomain: true,
    }),
  );
  resistances?.forEach((r, i) =>
    out.push({
      id: `resistance-${i}`,
      y: r.price,
      color: withAlpha(CHART.loss, 0.4),
      dash: "4 4",
      label: `R ${r.price.toFixed(2)}`,
      labelSide: "left",
      labelSize: 9,
      labelColor: withAlpha(CHART.loss, 0.5),
      extendDomain: true,
    }),
  );
  if (fibonacci) {
    for (const [label, price] of Object.entries(fibonacci.levels)) {
      out.push({
        id: `fib-${label}`,
        y: price,
        color: withAlpha(FIB, 0.25),
        dash: "2 4",
        label,
        labelSide: "right",
        labelSize: 8,
        labelColor: withAlpha(FIB, 0.4),
        extendDomain: true,
      });
    }
  }
  return out;
}

function TrendCaption({ support, resistance }: { support: TrendLine | null; resistance: TrendLine | null }) {
  const dir = (l: TrendLine) => (l.direction === "up" ? "rising" : "falling");
  // Says what was drawn and, just as important, what was not: the overlay on
  // with no line is a stock whose pivots do not line up, not a chart that forgot.
  return (
    <View className="mt-2">
      <AppText className="text-[10px] leading-relaxed text-white/30">
        {support || resistance ? (
          <>
            Trendline through the last 3 pivot{" "}
            {support ? (
              <AppText className="text-[10px]" style={{ color: TREND_SUPPORT_STROKE }}>
                lows ({dir(support)})
              </AppText>
            ) : null}
            {support && resistance ? " and " : null}
            {resistance ? (
              <AppText className="text-[10px]" style={{ color: TREND_RESISTANCE_STROKE }}>
                highs ({dir(resistance)})
              </AppText>
            ) : null}
            , dots mark the anchors.
          </>
        ) : (
          "No trendline: the last 3 pivots do not line up, or price has not respected the line."
        )}
      </AppText>
      <Pressable
        accessibilityRole="link"
        onPress={() => router.push(learnHref("trendlines"))}
        className="min-h-[44px] justify-center self-start"
      >
        <AppText className="text-[10px] text-accent/60">Learn more →</AppText>
      </Pressable>
    </View>
  );
}
```

```tsx
export interface VolumeDataPoint {
  date: string;
  volume: number;
  close: number;
  open: number;
  /** Previous session's close — drives the up/down colouring. */
  prevClose?: number;
}

export interface VolumeChartProps {
  data: VolumeDataPoint[];
  height?: number;
}

const UP = withAlpha(CHART.gain, 0.5);
const DOWN = withAlpha(CHART.loss, 0.5);
const FROM_ZERO = { min: 0 };

/**
 * An "up day" is close vs the PREVIOUS close — the definition used by the
 * price change, the sparkline and the backend's volume/price confirmation.
 */
export function volumeBarColors(data: readonly VolumeDataPoint[]): string[] {
  return data.map((d, i) => {
    const reference = d.prevClose ?? data[i - 1]?.close ?? d.open;
    return d.close >= reference ? UP : DOWN;
  });
}

const formatVolumeReadout = (v: number) => formatCompact(v);

export function VolumeChart({ data, height = 120 }: VolumeChartProps) {
  const labels = useMemo(() => data.map((d) => d.date), [data]);
  const series = useMemo<XYSeries[]>(() => {
    const colors = volumeBarColors(data);
    return [
      {
        kind: "bars",
        id: "volume",
        name: "Volume",
        values: data.map((d) => d.volume),
        colorAt: (_v, i) => colors[i],
      },
    ];
  }, [data]);

  if (!data.length) return null;

  return (
    <View className="rounded-xl border border-white/5 bg-white/[0.02] p-4">
      <AppText className="mb-2 text-xs text-white/40">Volume</AppText>
      <XYChart
        testID="volume-chart"
        labels={labels}
        series={series}
        height={height}
        yDomain={FROM_ZERO}
        yAxisWidth={45}
        xMinTickGap={50}
        verticalGrid={false}
        yTickFormat={formatCompact}
        readoutFormat={formatVolumeReadout}
      />
    </View>
  );
```

Create `src/charts/MonteCarloChart.tsx`:
```tsx
import { useMemo } from "react";
import { View } from "react-native";

import type { MonteCarloResult } from "@/shared/types";
import { AppText } from "@/ui";

import { formatCompact } from "./kit/format";
import { CHART, withAlpha } from "./kit/palette";
import { XYChart } from "./kit/XYChart";
import type { LineSeries, XYSeries } from "./kit/xyModel";

export interface MonteCarloChartProps {
  data: MonteCarloResult;
}

/**
 * Percentile outcomes arrive as growth MULTIPLIERS (1.0 = flat). Sign and
 * colour are read off the value — the "best case" can be a loss for a
 * portfolio with strong downward drift.
 */
export function formatOutcome(multiplier: number): string {
  const pct = (multiplier - 1) * 100;
  return `${pct >= 0 ? "+" : ""}${pct.toFixed(1)}%`;
}

export function outcomeToneClass(multiplier: number): "text-gain" | "text-loss" {
  return multiplier >= 1 ? "text-gain" : "text-loss";
}

export function lossChanceToneClass(p: number): "text-loss" | "text-yellow-400" | "text-gain" {
  return p > 0.5 ? "text-loss" : p > 0.3 ? "text-yellow-400" : "text-gain";
}

type Pctl = "p5" | "p25" | "p50" | "p75" | "p95";
const NAMES: Record<Pctl, string> = {
  p95: "Best 5%",
  p75: "75th pctl",
  p50: "Median",
  p25: "25th pctl",
  p5: "Worst 5%",
};

export function monteCarloSeries(data: MonteCarloResult): { labels: string[]; series: XYSeries[] } {
  const n = Math.max(0, Math.floor(data.days));
  const egp = (k: Pctl) =>
    Array.from({ length: n }, (_, i) => {
      const m = data.percentiles[k]?.[i];
      return typeof m === "number" && Number.isFinite(m) ? Math.round(data.initial_value * m) : null;
    });
  const v = { p5: egp("p5"), p25: egp("p25"), p50: egp("p50"), p75: egp("p75"), p95: egp("p95") };
  // Hidden lines: in the readout (and the domain) but drawn as the bands.
  const hidden = (k: Pctl): LineSeries => ({ kind: "line", id: k, name: NAMES[k], values: v[k], color: CHART.accent, hidden: true });
  return {
    labels: Array.from({ length: n }, (_, i) => String(i + 1)),
    series: [
      { kind: "band", id: "outer", lower: v.p5, upper: v.p95, fill: withAlpha(CHART.accent, 0.08) },
      { kind: "band", id: "inner", lower: v.p25, upper: v.p75, fill: withAlpha(CHART.accent, 0.12) },
      hidden("p95"),
      hidden("p75"),
      { kind: "line", id: "p50", name: NAMES.p50, values: v.p50, color: CHART.accent, width: 2 },
      hidden("p25"),
      hidden("p5"),
    ],
  };
}

const dayTitle = (label: string) => `Day ${label}`;
const egpReadout = (v: number) => `${v.toLocaleString()} EGP`;

function Tile({ label, value, tone }: { label: string; value: string; tone: string }) {
  return (
    <View className="w-[48%] rounded-lg bg-white/[0.03] p-3">
      <AppText className="text-[10px] text-white/40">{label}</AppText>
      <AppText className={`font-mono-semibold text-sm ${tone}`}>{value}</AppText>
    </View>
  );
}

export function MonteCarloChart({ data }: MonteCarloChartProps) {
  const { labels, series } = useMemo(() => monteCarloSeries(data), [data]);
  const { days, probability_of_loss } = data;

  return (
    <View className="rounded-xl border border-white/5 bg-white/[0.02] p-6">
      <AppText className="mb-4 font-sans-semibold text-lg text-white">Monte Carlo Simulation</AppText>
      <AppText className="mb-4 text-xs text-white/40">
        1,000 simulated scenarios over {days} days based on your portfolio&apos;s historical behavior.
      </AppText>

      <XYChart
        testID="monte-carlo-chart"
        labels={labels}
        series={series}
        height={250}
        yAxisWidth={55}
        yTickFormat={formatCompact}
        readoutTitle={dayTitle}
        readoutFormat={egpReadout}
      />
      <AppText className="mt-1 text-center text-[10px] text-white/30">Days</AppText>

      <View className="mt-4 flex-row flex-wrap justify-between gap-y-3">
        <Tile
          label="Chance of Loss"
          value={`${(probability_of_loss * 100).toFixed(0)}%`}
          tone={lossChanceToneClass(probability_of_loss)}
        />
        <Tile label="Worst Case (5%)" value={formatOutcome(data.worst_case_5pct)} tone={outcomeToneClass(data.worst_case_5pct)} />
        <Tile label="Median Outcome" value={formatOutcome(data.median)} tone={outcomeToneClass(data.median)} />
        <Tile label="Best Case (95%)" value={formatOutcome(data.best_case_95pct)} tone={outcomeToneClass(data.best_case_95pct)} />
      </View>
    </View>
  );
}
```

NativeWind only generates classes it can find as whole strings in the source. `text-gain`, `text-loss` and `text-yellow-400` appear verbatim in `outcomeToneClass` / `lossChanceToneClass`, so passing them through `tone` is safe.

```tsx
const finite = (v: unknown): v is number => typeof v === "number" && Number.isFinite(v);

export function correlationPairs({ symbols, matrix }: CorrelationMatrix): {
  high: CorrelationPair[];
  low: CorrelationPair[];
} {
  const high: CorrelationPair[] = [];
  const low: CorrelationPair[] = [];
  for (let i = 0; i < symbols.length; i++) {
    for (let j = i + 1; j < symbols.length; j++) {
      const c = matrix[i]?.[j];
      if (!finite(c)) continue;
      if (c > 0.7) high.push({ a: symbols[i], b: symbols[j], corr: c });
      else if (c < -0.3) low.push({ a: symbols[i], b: symbols[j], corr: c });
    }
  }
  return { high, low };
}
```

```js
  const out = values.map(() => null);

function bollinger(xs, n = 20, k = 2) {

  const middle = [];
  const lower = [];

    if (i < n - 1) {
      upper.push(null);
      middle.push(null);
      lower.push(null);
      return;
    }
    const win = xs.slice(i - n + 1, i + 1);
    const m = mean(win);
    const sd = Math.sqrt(mean(win.map((v) => (v - m) ** 2)));
    upper.push(r3(m + k * sd));
    middle.push(r3(m));
    lower.push(r3(m - k * sd));

      const d = xs[j] - xs[j - 1];
      if (d >= 0) gain += d;
      else loss -= d;
    }
    return loss === 0 ? 100 : r2(100 - 100 / (1 + gain / loss));
  });
```
